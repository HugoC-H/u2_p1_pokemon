## Decisiones técnicas
Explica brevemente:
- Las páginas principales estan ubicadas en la raíz de la carpeta mientras que los recursos a los que acceden estan organizados mayormente en carpetas.
- En cada página se repite tanto el inicio como el final del documento para organizar el html, la etiqueta head salvo los titulos de cada página, dentro del body el header salvo el titulo principal y el footer.
- El elemento cambiante entre caa página siempre ha sido el main dentro del body.
- Hay diferentes formatos de imagen para representar que no hay diferencias mayores entre ellos, destaca png por su compatibilidad con la transparencia pero en el resto son casi identicos.
- Las rutas relativas siempre han hecho referencia al archivo que se buscaba siguiendo ordenadamente el orden de carpetas.
- El proyecto se ha hecho siguiendo lo más fielmente posible la guía proporcionada por el docente.
